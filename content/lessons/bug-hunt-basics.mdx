You know the tools now — variables, functions, conditionals, loops, events. Bugs in this section are rarely big. They're one character: a missing `local`, a single `=` where you meant `==`, a `task.wait` that never got written. This lesson is a training ground for exactly those.

<Step>

## Hunt one — the missing local

<FixBug
  instruction="Add the missing declaration so the variable stays local."
  fix={["local coins = 0"]}
  placeholder="local coins = ..."
  requireLocal
  explanation="Without local, Luau makes a global variable — visible to every script. Every variable you own gets local."
  label="Hunt one"
>

```luau
coins = 0
```

</FixBug>

</Step>

<Step>

## Hunt two — the wrong equals

<FixBug
  instruction="Type the corrected line so the comparison works."
  fix={["if coins == 5 then"]}
  placeholder="if coins ... then"
  explanation="One = stores a value. An if is a question, and questions use == to compare."
  label="Hunt two"
>

```luau
if coins = 5 then
```

</FixBug>

</Step>

<Step>

## Hunt three — the frozen game

Press Play and your game freezes instantly. Output shows no error — the game is stuck inside a loop that never ends and never breathes.

<FixBug
  instruction="Write the line that pauses the loop so the game doesn't freeze."
  fix={["task.wait()", "task.wait(1)"]}
  placeholder="task.wait(...)"
  explanation="while true never ends. Without task.wait to pause each lap, the game can't do anything else — a hard freeze."
  label="Hunt three"
>

```luau
while true do
    print("tick")
end
```

</FixBug>

</Step>

<Step>

## Hunt four — the nil argument

<FixBug
  instruction="Write the corrected call that passes the amount."
  fix={["addCoins(5)"]}
  placeholder="addCoins(...)"
  explanation="The function expects amount. Called with empty parentheses, amount is nil — and nil + 1 errors. Call it with a number: addCoins(5)."
  label="Hunt four"
>

```luau
function addCoins(amount)
    coins = coins + amount
end

addCoins()
```

</FixBug>

</Step>

<Step>

## Hunt five — type the fix

A coin counter never changes. Spot the bug in the snippet and type the fixed line.

<FixBug
  instruction="Type the corrected line so the counter actually counts."
  fix={["coins = coins + 1"]}
  explanation="coins == coins + 1 compares instead of assigning. A single = stores the new value."
  placeholder="coins = ..."
  label="Hunt five"
>

```luau
local coins = 0

coins == coins + 1
```

</FixBug>

</Step>

<Step>

## Hunt six — put the loop together

One last hunt, but this time you assemble it. Arrange the lines so a part's click gives the player a coin each time — no imposters.

<ArrangeCode
  lines={[
    "button.ClickDetector.MouseClick:Connect(function(player)",
    "    local coins = player.leaderstats.Coins",
    "    coins.Value = coins.Value + 1",
    "end)",
  ]}
  distractors={[
    "while true do",
    "coins.Value == coins.Value + 1",
    "player.leaderstats.Coins = 1",
  ]}
  explanation="Connect the event, grab the player's Coins, count one up, and close the callback. The distractors loop forever or compare instead of assigning."
/>

</Step>
