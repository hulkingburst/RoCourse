"Is this wall between me and the player? What's under my feet? Did my laser hit the target?" Games answer those questions with a **raycast**: an invisible ray fired from a point in a direction, with Roblox reporting back the first thing it hits.

<Step>

## The ray

A ray needs two things: a **starting point** and a **direction**. Fire it and Roblox tells you what it hit:

```luau
local origin = Vector3.new(0, 5, 0)      -- where the ray starts
local direction = Vector3.new(0, 0, -50) -- which way it goes, and how far (50 studs)

local result = workspace:Raycast(origin, direction)
```

- `origin` — a position the ray leaves from.
- `direction` — a vector whose *length* is the max distance the ray travels.
- Returns a **RaycastResult** — or `nil` if the ray hit nothing.

## Reading the hit

When the ray hits, the result tells you everything about the impact:

```luau
if result then
    print(result.Instance) -- the part the ray struck
    print(result.Position) -- the exact point it landed on
    print(result.Normal)   -- which way the surface faces
end
```

Three fields, three answers:

- `result.Instance` — **what** was hit (the part).
- `result.Position` — **where** the ray landed (a Vector3).
- `result.Normal` — which way that surface points, useful for placing things flush against it.

## Filtering the cast

A raw ray hits *everything* in its path — including the player who fired it. Filter it with `RaycastParams` so you don't shoot yourself:

```luau
local rayParams = RaycastParams.new()
rayParams.FilterType = Enum.RaycastFilterType.Exclude
rayParams.FilterDescendantsInstances = { player.Character }

local result = workspace:Raycast(origin, direction, rayParams)
```

- `FilterType.Exclude` — "hit everything *except* the list below."
- `FilterDescendantsInstances` — the parts to ignore (your own character model).
- The params go in as the **third argument** to `Raycast`.

## A real use: is there ground?

Cast a ray straight down from the character and you can read the height of the floor below — for landing checks, footsteps, or keeping a camera off the ceiling:

```luau
local rayParams = RaycastParams.new()
rayParams.FilterType = Enum.RaycastFilterType.Exclude
rayParams.FilterDescendantsInstances = { character }

local origin = character.HumanoidRootPart.Position
local direction = Vector3.new(0, -100, 0) -- straight down, up to 100 studs

local result = workspace:Raycast(origin, direction, rayParams)

if result then
    print("ground at", result.Position.Y)
end
```

Downward rays are the same recipe as any other ray — the trick is that the direction points *down*, and the filter keeps the ray from hitting the character itself.

## Common mistakes

- **Forgetting the nil check.** A ray that misses returns `nil` — `result.Instance` on a miss crashes. Always guard with `if result then`.
- **No filter, hit yourself.** A raw ray hits the player who fired it. Exclude your own character (or the parts you don't want).
- **Direction as a position.** `workspace:Raycast(origin, workspace.Target.Position)` fires a ray to a *point* far away, not toward the target. The direction must be a vector from the origin.
- **Reusing the same params forever.** One `RaycastParams` is fine for one cast. If different casts need different filters, make a new one — or rebuild the list.
